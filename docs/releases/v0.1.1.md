# v0.1.1: documentation only

No behavior changes. Website Health is now in the default HACS catalog, and the
README that HACS shows now leads with searching for it there. Adding it as a custom
repository stays as a fallback.

- The version number moves to 0.1.1 so the release carries the README. The version
  is part of the User-Agent the checks send, so that string changes with it.

## Upgrading

Update Website Health in HACS. No restart is needed for the documentation, but Home
Assistant will show the new version, and the checks will send the new User-Agent,
after its next restart.
